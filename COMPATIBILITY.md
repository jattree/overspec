## What the words mean

- **Good**: it loads, and its picture matches a reference emulator (Fuse) at the end of the run.
- **Runs**: it loads and runs. There is no reference emulator for this kind, so the picture was not compared.
- **Check**: it runs, but part of the picture differs from the reference. Often a different moment in a title sequence.
- **Differs**: it runs, but most of the picture differs from the reference. These need a look.
- **Fails**: it does not load or did not finish.
- **Save and restore**: a save taken part way and loaded again gives exactly the same picture, sound and state.

The automated run plays each file for a fixed time with no one at the controls. It does not show that a game can be played to the end, or that it sounds right. Games a person has played are listed separately below.
